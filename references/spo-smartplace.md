# SPO — 스마트플레이스 최적화 (네이버 지도 · 플레이스 검색 · AI 브리핑 지역 답변)

오프라인 업장(체육관·식당·병원·학원·미용실…)이라면 "○○동 크로스핏", "거여역 헬스장" 같은
**지역 + 업종 검색의 답은 홈페이지가 아니라 플레이스 카드**다. NEO 레인이 "내 도메인이
네이버에 인용되는가"를 다룬다면, SPO는 **내가 통제하지 못하는 네이버 호스팅 프로필**을
크롤러의 눈으로 진단하고 채우는 레인이다. 목표 세 개: ① 플레이스 검색 순위
② AI 브리핑·지도의 지역 답변에 카드로 노출 ③ 카드에서 전화·예약·톡톡으로 전환.

> 순위 로직은 네이버 비공개다. 이 레인은 "고치면 순위가 오른다"를 약속하지 않는다.
> 대신 **네이버가 스스로 누락으로 플래그하는 항목**과 **공개 페이지에서 측정 가능한 신호**를
> 전부 채우고, 센터 통계로 재측정한다.

## 0. 크롤러의 눈으로 진단 — 스크립트 먼저

플레이스 공개 페이지(`m.place.naver.com/place/{id}/home`)는 `window.__APOLLO_STATE__`에
업체 정보를 SSR로 내려준다. 로그인·API 없이 읽을 수 있다:

```bash
# naver.me 짧은 링크, 지도 URL, 숫자 ID 전부 받는다
python3 scripts/place-audit.py https://naver.me/xxxxxxx
python3 scripts/place-audit.py 1790538774 --json   # 원본 필드 전체
```

스크립트가 읽는 것 (실측 2026-09 기준 SSR 노출 필드):

| 필드 | 아폴로 키 | 진단 의미 |
|---|---|---|
| `missingInfo.is*Missing` | PlaceDetailBase | **네이버가 직접 찍은 누락 플래그** — 최우선 |
| `openingHours` / `hideBusinessHours` | PlaceDetailBase | 영업시간 존재 여부 |
| `roadAddress` / `road` | PlaceDetailBase | 주소 · 찾아오는 길 |
| `virtualPhone` / `phone` / `talktalkUrl` | PlaceDetailBase | 전환 경로 (스마트콜·톡톡) |
| `conveniences` / `paymentInfo` | PlaceDetailBase | 편의시설 · 결제수단 |
| `categoryCodeList` | PlaceDetailBase | 카테고리 매핑 수 |
| `Menu:*` | 상품·가격표 | "얼마예요" 질문의 답 |
| `VisitorReviewStatsResult` | 리뷰 통계 | 건수·평점·사진리뷰·테마 |
| `Feed:*` (feed 탭) | 소식 | 발행 주기 · 카테고리 · 블로그 연동 |
| `PlaceDetailTopPhotoItem` | 홈 대표 영역 | 업체 사진이 방문자 사진에 밀리는지 |
| `placeDetail.tabs` | 탭 목록 | `ticket`/`booking` 탭 = 예약 활성 |

**SSR에 안 실리는 것** (클라이언트 GraphQL로 후속 로드 — 스크립트가 🔎로 표시):
소개글, 대표키워드 5개, 홈페이지·SNS 링크, 전체 사진 수량. 이건 스마트플레이스 센터
(smartplace.naver.com)에서 사용자가 직접 확인하거나 화면 캡처를 받아 판단한다.

⚠️ 네이버 마크업은 예고 없이 바뀐다. 스크립트 필드가 통째로 비면 실제 누락이 아니라
파싱 실패일 수 있다 — 브라우저로 한 번 교차 확인하고, 깨졌으면 스크립트를 고친다.

## 1. 기본 정보 완성도 — 누락 플래그 0개가 기준선

- [ ] **`missingInfo` 플래그 전부 해소**: `isBizHourMissing`(영업시간), `isMenuImageMissing`
      (상품 이미지), `isDescriptionMissing`(소개), `isConveniencesMissing`(편의시설).
      네이버가 "덜 채워진 업체"로 분류하는 기준 자체이므로 다른 무엇보다 먼저
- [ ] **영업시간**: 요일별 + 휴게시간 + 정기휴무. 체육관처럼 수업제면 "수업 시간표"를
      소개글이나 상품 이미지에 넣고 영업시간에는 문 여는 시간을 적는다. 비워두면
      "영업 중" 필터에서 빠지고 AI 답변에서 "영업시간 정보 없음"으로 나간다
- [ ] **카테고리**: 대표 카테고리가 실제 업종과 일치하는가 ("헬스장"으로 크로스핏 박스를
      등록하는 건 맞다 — 네이버 분류에 크로스핏이 없다면 상위 분류 + 소개글·키워드로 보완)
- [ ] **찾아오는 길**: "○○역 N번 출구 도보 N분" 형식. 지하·건물 내 위치면 층·호수까지
- [ ] **편의시설·결제**: 해당하는 항목 전부 체크. 주차·화장실·와이파이·단체이용은 필터 조건이다
- [ ] **전화**: 스마트콜(0507) 연결 상태 확인 — 통화 통계가 센터에 잡히는 건 스마트콜뿐

## 2. 소개글 · 대표키워드 (🔎 수동 확인 항목)

- [ ] **소개글 첫 문장이 직답**: "거여역 4번 출구 2분, 무경험자 무료체험이 있는 크로스핏
      박스" 처럼 [지역 + 업종 + 차별점]을 첫 40자에. AEO의 "첫 문단 직답"과 같은 원리다 —
      AI 브리핑은 소개글 첫 문장을 그대로 인용하는 경우가 많다
- [ ] **대표키워드 5개**: "지역명 + 업종" 조합으로 실제 검색어를 쓴다
      (예: 거여동 크로스핏, 거여역 헬스장, 송파 크로스핏, 마천 크로스핏, 크로스핏 무료체험).
      브랜드명은 검색되면 어차피 잡히니 키워드 슬롯을 낭비하지 마라
- [ ] ❌ **업체명에 키워드 스터핑 금지**: "크로스핏 에이블 거여 송파 헬스 PT 다이어트" 같은
      이름은 네이버 업체명 정책 위반이고 노출 제한 사유다. 업체명 = 간판 이름

## 3. 상품 · 가격

- [ ] 주력 상품에 **숫자 가격**을 적는다. "문의"만 있는 가격표는 "○○ 얼마예요" 질문에
      답이 못 되고, 비교 검색에서 가격 있는 경쟁 업체에 밀린다
- [ ] 무료체험·상담 같은 **진입 상품을 첫 줄**에 (`index: 0`) — 카드에서 가장 먼저 보이는 상품
- [ ] 상품 이미지: `isMenuImageMissing` 플래그 해소. 시간표·시설 사진을 상품 이미지로 써도 된다
- [ ] 가격 변경 시 소식에도 같이 알린다 — 카드 가격과 소식 가격이 다르면 신뢰 감점

## 4. 리뷰 — 정공법만

- [ ] **방문자 리뷰 답글 100%**: 답글은 신뢰 신호이자 키워드 표면이다. 답글에 자연스럽게
      지역·업종·상품명을 넣되 복붙 답글은 스팸 패턴이다 — 리뷰 내용을 언급하며 쓴다
- [ ] **영수증·예약 리뷰 요청은 현장에서**: 결제 직후 "네이버 리뷰 남겨주시면 감사" 안내 문구·
      QR은 허용 범위. 리뷰 대가로 할인·사은품은 네이버 정책 위반(리뷰 어뷰징)
- [ ] **리뷰 테마 읽기**: 스크립트의 `themes`(서비스·위치·시설…)가 곧 고객이 말하는
      강점이다. 소개글·소식·블로그 글의 주제를 여기에 맞춘다
- [ ] **최근 30일 리뷰가 0이면 위험**: 리뷰 총량보다 최신 리뷰 유무가 "살아있는 업체" 판정에
      더 영향을 준다 (실측 관찰)
- [ ] 블로그 리뷰: 체험단으로 만든 리뷰가 방문자 리뷰보다 많으면 "광고 업체" 패턴.
      비율이 뒤집히지 않게

## 5. 소식(피드) — 신선도 신호

- [ ] **월 2회 이상**, 최근 90일 기준 6건 이상 유지. 스크립트의 `owner_posts_last_90d`
- [ ] **카테고리 섞기**: 알림·SALE·임시휴무·이벤트. "SALE"만 연속이면 광고 피드로 읽힌다
- [ ] **임시휴무는 반드시 소식으로**: 휴무 안 알리고 문 닫으면 "영업시간 틀림" 신고가 쌓인다
- [ ] **블로그 연동**: 네이버 블로그를 연결하면 블로그 글이 피드에 자동 수집된다
      (`Feed:{blogId}_*`). NEO의 inside 트랙과 같은 블로그를 써서 이중 관리 없이 간다
- [ ] 소식 본문에 [질문 → 직답] 구조를 쓴다: "처음인데 가능한가요? → 가능합니다. 첫 방문 시
      체력 확인 후 무게·난이도를 조절합니다." — AI 브리핑이 소식 문단을 인용하는 형태다

## 6. 전환 경로 — 세 개 다 열어라

- [ ] **예약**: `tabs`에 `ticket`/`booking`이 있는가. 무료체험·상담을 예약 상품으로 만들면
      "예약 가능" 배지가 붙고 AI 답변에서 "예약은 네이버에서" 로 유도된다
- [ ] **톡톡**: `talktalkUrl` 존재 + 응답률 관리(센터 통계). 자동응답 첫 문장에 영업시간·위치
- [ ] **전화(스마트콜)**: `virtualPhone` 존재. 부재중 안내 멘트에 톡톡 유도
- [ ] 전환 통계는 센터 > 통계 > "전화·길찾기·예약·톡톡 클릭"이 유일한 출처다. 주 1회 스냅샷

## 7. 사진 · 영상

- [ ] **홈 대표 영역이 업체 사진으로 채워지는가**: 스크립트의 `business_photos_in_top`.
      대표 영역 10칸이 방문자 사진에 밀리면 첫인상을 통제 못 하는 것 — 업체 사진을
      최근 날짜로 갱신하면 상단으로 올라온다
- [ ] 외부 간판·내부 전경·시설·수업 장면·시간표·코치 프로필 최소 10장, 가로·세로 섞어서
- [ ] **클립(숏폼)**: 플레이스에 연결된 클립은 대표 영역에 영상으로 뜬다. 해시태그에
      `#업체명 #지역+업종`을 넣어야 플레이스와 매칭된다 (실측: 해시태그로 연결됨)
- [ ] 대표 사진 파일명·업로드 날짜가 2년 이상 오래되면 교체 — "오래된 업체" 신호

## 8. 엔티티 일관성 — 플레이스 ↔ 내 도메인 ↔ SNS

LLMO 레인의 원리를 오프라인 업장에 적용한다. **이름·주소·전화(NAP)를 모든 표면에서
글자 단위로 동일하게**:

- [ ] 플레이스 업체명 = 홈페이지 `<title>` = 인스타그램 프로필명 = 블로그명 = 간판
      ("크로스핏 에이블 거여" vs "에이블 거여" vs "ABLE GEOYEO"가 섞이면 엔티티 분열)
- [ ] 자기 도메인이 있으면 `LocalBusiness`(또는 `SportsActivityLocation`·`Restaurant` 등
      하위 타입) JSON-LD를 넣고 `sameAs`에 플레이스 URL(`https://m.place.naver.com/place/{id}`),
      인스타그램, 블로그를 전부 나열 — "이 이름들이 전부 같은 실체"라는 선언
- [ ] 플레이스 소개글·소식에서 자기 도메인 링크를 텍스트로라도 노출 (NEO의 outside 트랙 연결)
- [ ] `og:title`이 `{업체명} : 네이버`로 생성되므로 업체명 자체가 검색 스니펫이다 —
      업체명에 지역명이 들어가면(예: "○○ 거여") 지역 검색 매칭에 유리하고 정책 위반도 아니다

## 9. 하지 말 것 (플레이스는 신고·제재가 빠르다)

- ❌ 리뷰 구매·대가성 리뷰·지인 동원 방문자 리뷰 — 어뷰징 판정 시 리뷰 삭제 + 노출 제한
- ❌ 업체명 키워드 스터핑, 카테고리 허위 등록(헬스장을 "병원"으로 등)
- ❌ 같은 업장을 여러 플레이스로 중복 등록 — 리뷰가 갈리고 하나가 폐업 처리될 수 있다
- ❌ 영업시간·가격을 자주 바꾸기 — 변경 이력이 잦으면 정보 신뢰도가 떨어진다
- ❌ 소식에 같은 문구 반복 발행 — 네이버 블로그와 같은 스팸 필터가 돈다

## 10. 측정

플레이스에는 서치어드바이저 같은 API가 없다. 두 층으로 잰다:

1. **공개 신호 (스크립트, 자동)**: 방문자 리뷰 수·최근 리뷰 날짜·소식 90일 건수·누락 플래그.
   `--json` 출력을 날짜별로 저장해 diff
2. **센터 통계 (수동, 주 1회)**: 플레이스 조회수, 유입 검색어 Top, 전화·길찾기·예약·톡톡 클릭.
   **유입 검색어 Top이 대표키워드 후보 목록이다** — 상위 검색어 중 대표키워드에 없는 것 =
   다음에 넣을 키워드
3. **순위 스냅샷**: 대표키워드 5개를 네이버 앱(모바일)에서 검색해 플레이스 순위와
   AI 브리핑 지역 답변 노출 여부를 O/X로 기록. 위치 기반이라 **같은 장소·같은 시간대**에서 재야
   비교가 된다

```
[기준선] 9/7: 누락 플래그 1(영업시간) · 방문자 리뷰 127 · 90일 소식 5 · 순위 "거여동 크로스핏" 2위
[변경] 9/8: 영업시간 등록 + 대표키워드 5개 + 무료체험 예약상품 + 업체 사진 8장 갱신
[재측정 예약] 9/22
[재측정 결과] 누락 0 · 리뷰 134 · 소식 8 · 순위 1위 · 예약 클릭 12 → 31   ← 이게 나와야 완료
```
