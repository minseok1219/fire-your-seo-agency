# KMO — 카카오맵 최적화 (카카오맵 · 카카오톡 검색 · 톡채널 전환)

네이버 다음으로 큰 지도 채널이지만 대부분의 업장이 **등록만 해두고 방치**한다. 그래서 KMO의
본체는 새로 무언가를 만드는 게 아니라 **네이버 스마트플레이스와 글자 단위로 맞추는 것**이다.
카카오로 들어온 손님이 네이버와 다른 영업시간·가격·휴무를 보면 그 손님은 둘 다 안 믿는다.
목표 세 개: ① 네이버와 NAP(이름·주소·전화·시간·가격) 일치 ② 비어 있는 카카오맵 리뷰·소식 채우기
③ 톡채널·카카오 예약으로 전환.

> 순위 로직은 카카오 비공개다. 이 레인은 "고치면 순위가 오른다"를 약속하지 않는다.
> 대신 **공개 API에서 실제 필드로 측정 가능한 신호**를 채우고, 네이버와의 불일치를 0으로 만든다.

## 0. 크롤러의 눈으로 진단 — 스크립트 먼저

카카오맵 웹이 쓰는 검색 엔드포인트와 플레이스 패널 API가 로그인·키 없이 JSON을 준다:

```bash
python3 scripts/kakao-audit.py --name "업체명"                         # 검색 → 첫 결과 진단
python3 scripts/kakao-audit.py https://place.map.kakao.com/641759795   # URL 또는 숫자 ID
python3 scripts/kakao-audit.py 641759795 --naver https://naver.me/xxxx # 네이버와 필드별 대조 ★
python3 scripts/kakao-audit.py 641759795 --json                        # 원본 필드 전체
```

스크립트가 읽는 것 (실측 2026-09, `place-api.map.kakao.com/places/panel3/{id}`):

| 필드 | 진단 의미 |
|---|---|
| `summary.name` / `address` / `phone_numbers` / `homepages` | NAP + 외부 링크 (홈페이지·인스타·블로그가 한 배열에) |
| `summary.meta.updated_at` | 업체 정보 마지막 갱신일 |
| `open_hours.all.periods` / `all_days_off_info` | 요일별 영업시간 · 정기휴무 · **공휴일 정책** |
| `menu.menus.items` / `items_updated_at` | 상품·가격 + **가격표 갱신일** (1년 넘으면 ⚠️) |
| `kakaomap_review.score_set` | 카카오맵 자체 리뷰 수·평점 (네이버 리뷰와 별개 채널) |
| `blog_review.review_count` | 블로그 리뷰 수 |
| `my_store_notice` | 매장관리 등록 여부 · 소식 수 |
| `talk_channel` / `reservation` / `available_tickets` | 톡채널(친구 수) · 카카오 예약 · 예약 상품 |
| `photos.counts` | 매장주 사진 / 전체 / 실내·실외 |
| `place_add_info.tags` / `facilities` | 태그 · 주차 |
| `find_way.subway` | 찾아오는 길 (역·출구·거리) |

⚠️ 비공식 엔드포인트다. `pf: web`·`Origin`·`Referer` 헤더가 없으면 406이 난다. 깨지면
place.map.kakao.com을 브라우저 개발자도구로 열어 실제 요청 헤더를 다시 맞춘다.

## 1. 네이버와 대조 — KMO의 본체

`--naver`로 대조표를 뽑아 **불일치 0건**을 만든다. 정본은 하나로 정한다(보통 네이버, 리뷰가
많은 쪽). 실측에서 잡힌 불일치 유형:

- [ ] **업체명 띄어쓰기**: "크로스핏에이블 거여"(카카오) vs "크로스핏 에이블 거여"(네이버).
      검색엔진과 모델은 이걸 다른 엔티티로 본다. 간판 표기 하나로 통일
- [ ] **영업시간 분 단위 차이**: 06:30 vs 06:15. 어느 쪽이 사실인지 확인하고 다른 쪽을 고친다 —
      한쪽이 옛날 값이 남은 것이다
- [ ] **공휴일 정책 충돌**: 카카오 "공휴일 휴무" vs 네이버 "공휴일 영업은 인스타로 확인".
      카카오로 온 손님은 공휴일에 문 닫은 줄 안다. 실제 정책을 양쪽에 같은 문장으로
- [ ] **가격표 누락**: 네이버에 있는 진입 상품(무료체험·상담·단체 할인)이 카카오에 없음.
      카카오 가격표는 `items_updated_at`이 1년 넘게 멈춰 있는 경우가 흔하다
- [ ] **주소 상세 표기**: 도로명·번지가 같아도 건물명·층 표기가 다르면 ⚠️. 통일 권장
- [ ] **카테고리**: 카카오 "스포츠시설" vs 네이버 "헬스장"처럼 분류 체계가 달라 완전 일치는
      불가능하다. 각 플랫폼에서 가장 좁은 정확한 분류를 고르면 된다 (불일치 아님)

## 2. 매장관리 등록 (전제 조건)

- [ ] `my_store_notice.status == REGISTERED`인가. 미등록이면 정보 수정·소식·예약·톡채널
      연결 전부 불가 — 카카오맵 매장관리(https://store.kakao.com 계열)에서 사업자 인증부터.
      사용자 계정이 필요하니 절차를 안내한다
- [ ] 등록되어 있으면 `summary.meta.updated_at`을 본다 — 6개월 이상 안 움직였으면 방치 상태

## 3. 리뷰 — 카카오맵 리뷰는 별도 채널이다

네이버 방문자 리뷰가 100건이어도 카카오맵 리뷰는 0건인 업장이 대부분이다. 카카오맵 앱에서
검색한 사람은 네이버 리뷰를 못 본다.

- [ ] **후기 요청 QR에 카카오맵을 추가**: 네이버 리뷰 QR 옆에 카카오맵 리뷰 QR. 결제 후 안내
      문구는 허용 범위, 리뷰 대가 할인·사은품은 어뷰징
- [ ] **리뷰 답글**: 카카오맵도 매장주 답글이 된다. 네이버와 같은 원칙 — 복붙 금지, 리뷰 내용 언급
- [ ] `kakaomap_review.strength_description`(가격·전문성·친절…)이 카카오가 이 업종에서
      묻는 강점 항목이다. 소개글·소식이 그 항목에 답하게
- [ ] 블로그 리뷰(`blog_review`)는 네이버 블로그를 카카오가 수집한 것 — NEO 레인의 블로그
      트랙이 여기서도 먹힌다

## 4. 소식 — 네이버 소식을 복제 발행하라

- [ ] `my_store_notice.notice_count == 0`이면 ❌. 네이버 스마트플레이스에 올리는 소식을
      **같은 날 카카오 매장관리에도** 올린다. 새 글을 쓰는 게 아니라 복제다 — 임시휴무·이벤트·
      가격 변경은 특히 양쪽 동시에 (한쪽만 올리면 1번 대조표에 불일치로 잡힌다)
- [ ] 소식 본문은 [질문 → 직답] 구조 (SPO 5번과 동일)

## 5. 전환 경로 — 톡채널이 핵심

카카오의 차별점은 **카카오톡 안에서 끝나는 전환**이다. 지도에서 톡채널 → 채팅 → 예약까지
앱을 안 바꾼다.

- [ ] **톡채널 연결** (`talk_channel`): 친구 수가 곧 재방문 푸시 대상이다. 첫 방문 시
      "톡채널 추가하면 시간표·휴무 알림" 같은 실질 혜택으로 친구를 모은다 (할인 대가는 아님)
- [ ] **카카오 예약** (`reservation` + `available_tickets`): 무료체험·상담을 예약 상품으로.
      네이버 예약과 같은 상품 구성으로 (한쪽에만 있는 상품 = 불일치)
- [ ] **전화**: 카카오는 일반 번호(02-…)가 실리고 네이버는 스마트콜(0507-…)이 실린다.
      번호가 다른 건 정상이다 — 둘 다 같은 곳으로 울리는지만 확인
- [ ] 톡채널 자동응답 첫 문장에 영업시간·위치·무료체험 안내

## 6. 사진 · 태그

- [ ] `photos.counts.mystore`(매장주 사진)가 10장 미만이면 보강. 카카오는 실내/실외를 따로
      세므로 **실외(간판) 사진 0장**이면 지도에서 찾아오는 손님이 건물을 못 찾는다
- [ ] `place_add_info.tags`: 카카오가 자동 부여하는 태그(다이어트·크로스핏·문화비소득공제 등).
      매장관리에서 직접 수정은 제한적이지만, 소개글·상품명에 쓰는 단어가 태그로 반영된다
- [ ] 문화비 소득공제 가맹점이면 `events`에 자동 노출된다 — 체육시설은 등록 가치가 있다

## 7. 엔티티 일관성 — 자기 도메인과 연결

- [ ] `summary.homepages`에 홈페이지·인스타그램·네이버 블로그가 전부 있는가. 카카오는 한 배열에
      세 종류를 넣을 수 있어 SPO보다 sameAs 근거를 만들기 쉽다
- [ ] 자기 도메인 `LocalBusiness` JSON-LD의 `sameAs`에 카카오맵 URL
      (`https://place.map.kakao.com/{id}`)도 추가 — 네이버·카카오·인스타·블로그가 한 실체라는 선언
- [ ] 톡채널 이름(`talk_channel.name`)도 업체명과 동일하게 — "크로스핏에이블거여"처럼
      띄어쓰기가 또 다르면 표기가 세 가지가 된다

## 8. 하지 말 것

- ❌ 카카오맵 리뷰 구매·지인 동원 — 네이버와 같은 어뷰징 기준, 톡채널까지 제재될 수 있다
- ❌ 같은 업장 중복 등록 — 카카오는 중복 신고 처리가 빨라 하나가 비공개된다
- ❌ 네이버와 다른 가격·시간을 "카카오용 프로모션"으로 두기 — 손님은 비교하고, 신뢰만 깎인다
- ❌ 톡채널 대량 메시지 남발 — 차단률이 오르면 채널 자체 노출이 줄어든다

## 9. 측정

카카오맵 매장관리 통계(조회·전화·길찾기·톡채널 클릭)는 센터에서만 보인다. 두 층으로 잰다:

1. **공개 신호 (스크립트, 자동)**: `--naver` 대조표의 불일치 건수, 카카오맵 리뷰 수, 소식 수,
   가격표 갱신일, 톡채널 친구 수. `--json`을 날짜별로 저장해 diff
2. **센터 통계 (수동, 주 1회)**: 매장관리 > 통계. 유입 검색어는 네이버 서치어드바이저·스마트플레이스
   센터와 합쳐 대표키워드 후보로

```
[기준선] 9/7: 네이버 대조 불일치 9건 · 카카오맵 리뷰 0 · 소식 0 · 가격표 갱신 2024-09 · 톡채널 친구 21
[변경] 9/8: 업체명·영업시간·공휴일 문구 네이버에 맞춤 + 무료체험·단체할인 상품 추가 + 소식 3건 복제 + 리뷰 QR에 카카오맵 추가
[재측정 예약] 9/22
[재측정 결과] 불일치 0 · 리뷰 4 · 소식 5 · 톡채널 친구 33   ← 이게 나와야 완료
```
